# registration-form
Responsive coffee-themed registration page built with HTML, CSS, and JavaScript, featuring real-time validation, password visibility toggle, and password strength feedback.

#Registration Page

A stylish and responsive registration page inspired by premium coffee brands, built using HTML, CSS, and JavaScript. The project combines an elegant coffee-themed design with interactive form validation and a user-friendly experience.

## ✨ Features

- Elegant coffee-inspired UI with warm colors and refined typography
- Responsive layout for desktop, tablet, and mobile devices
- Real-time name and email validation
- Password validation with a minimum of 6 characters
- Show/Hide password functionality
- Dynamic password strength indicator
- Submit button enabled only when all fields are valid
- Success message after valid form submission
- Accessible form labels, error messages, and keyboard focus states

## 🛠️ Technologies Used

- HTML5 — Semantic page structure
- CSS3 — Styling, responsive layouts, transitions, and animations
- JavaScript — Form validation and interactive functionality
- Google Fonts — Typography

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Try the form using valid and invalid inputs.

## 📝 Note
